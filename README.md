# Finance

Meine Finanz-Werkzeuge für Claude Code.

- **`Cheatsheet.md`** erklärt alle Finanz-Plugins auf Deutsch und für Einsteiger.
- **`.claude/commands/aktie.md`** ist der Befehl `/aktie <Name>` für eine vollständige Aktienanalyse.
- **`Analysen/`** enthält die gespeicherten Aktienanalysen (Bericht als Markdown und PDF, Excel-Modelle).
- **`tools/bericht_pdf.py`** macht aus einem Bericht ein lesbares PDF: `python3 tools/bericht_pdf.py "Analysen/<Aktie>/Bericht.md"`.

**Nutzung:** Starte eine Claude-Code-Sitzung mit diesem Repository und tippe zum Beispiel `/aktie SAP`.

*Keine Anlageberatung.*
